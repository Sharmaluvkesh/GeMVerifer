# GeMVerifier - Version Release History

---

## 📌 Version 3 (`/versions/version_3`) — Latest Milestone
**Release Date**: August 29, 2026
**Key Features & Enhancements**:
- **Sticky Floating 3D GeM-Bot Mascot**: Always-visible fixed mascot at bottom-right corner (`fixed bottom-6 right-6 z-50`) with an animated speech bubble (`"Hi! I'm GeM-Bot 🤖 Click to ask AI!"`).
- **Interactive GeM-Bot AI Assistant Drawer**: Modal chat assistant with prompt pills (*Why Apex Disqualified?*, *CPU Core Requirement*, *Required Certificates*) for instant AI tender diagnosis.
- **Scroll-Driven Rotating Tech Orbit Ring**: Dynamic background SVG orbit ring that rotates in real-time as the user scrolls.
- **Bigger Verified OEM Supplier Cards**: High-definition hardware product photos (*Dell Precision Workstation, HP ZBook Studio, TechNova Workstation*) alongside official brand badges and turnover statistics.
- **Interactive OEM Verification Pre-Check Modal**: Clicking any supplier card opens an interactive verification drawer with real-time tender match scores (*100% Score*, *98.2% Score*, *96.5% Score*) and catalog audit navigation.

## 📌 Version 2 (`/versions/version_2`)
**Release Date**: August 29, 2026
**Key Features & Enhancements**:
- **User Personalization & Auth Engine**: Shaft-hash passwords, JWT tokens, `/api/auth/register`, `/api/auth/login`, and persona switches (`VENDOR`, `BIDDER`, `BOTH`).
- **Multi-Tab Dashboard Views**: Switchable views for Overview Command Dashboard, Buyer Portal, Vendor Pre-Check, Compliance Matrix, and Account Settings.
- **MyGov.in Tricolor Aesthetic & Moving Cards Carousel**: Added government tricolor line, live ticker marquee bar, and pop-out hover scale cards (`scale-108`, `shadow-2xl`).
